# Repositorio del curso

## Estructura

Este repositorio se usará durante todo el semestre para organizar laboratorios, ejercicios y herramientas compartidas.

## Carpetas

- `laboratorios/`: informes de laboratorio evaluativos del semestre.
- `ejercicios-clase/`: ejercicios prácticos de las sesiones, incluyendo Python de la Semana 2.
- `benchmarks/`: scripts compartidos para medir tiempos y generar gráficas.

## Ejemplo de uso

```bash
git status
git add .
git commit -m "Describe el cambio realizado"
```
