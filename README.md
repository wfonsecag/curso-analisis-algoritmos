# Repositorio del curso

Este repositorio se usará durante todo el semestre para organizar el trabajo de la asignatura de Análisis de Algoritmos.

## Estructura

Las carpetas principales del proyecto tienen un propósito fijo desde el inicio:

- `laboratorios/`: informes de laboratorio evaluativos del semestre.
- `ejercicios-clase/`: ejercicios prácticos de las sesiones, incluyendo Python de la Semana 2.
- `benchmarks/`: scripts compartidos para medir tiempos y generar gráficas.

## Flujo de trabajo

1. Crear o modificar archivos en la carpeta del proyecto.
2. Revisar los cambios con `git status` y `git diff`.
3. Agregar los archivos correctos con `git add`.
4. Guardar el avance con un mensaje de commit descriptivo.

## Verificación rápida

```bash
git status
git log --oneline
```
